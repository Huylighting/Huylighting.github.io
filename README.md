# Huylighting Portfolio

Personal portfolio about Linux, networking, home servers, open-source projects and stage technology.

## Website files

- `index.html` — page content and metadata
- `style.css` — responsive dark theme with stage-light-inspired accents
- `script.js` — accessible mobile navigation

## Publish with GitHub Pages

1. Open this repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for the deployment to finish. The site should be available at https://huylighting.github.io/.

This is a static site. It does not require a server, database, build step, or secrets. External links are used for GitHub and official documentation.

## Customize

Edit the content in `index.html`, colors and layout in `style.css`, and navigation behavior in `script.js`. Commit changes to `main`; GitHub Pages will publish updates automatically after the build completes.
